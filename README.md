# Knotter

Infinite canvas workspace for creating and editing graphs.

## Tech

- Next.js 16
- React 19
- TypeScript 5
- Tailwind CSS 4
- Zustand 5

## Pages

- [Main](https://knotter.io/)
- [Canvas](https://knotter.io/canvas/)

## Build

```bash
npm i
npm run dev
```
